Claude Code 2.1.325 更新日誌

翻譯自 官方 CHANGELOG

2.1.325

  • 修正 zstd 壓縮回應解碼方式中的一個安全性問題
  • 在 VS Code 與類似的整合式終端機中新增 spinner 提示,告訴你可以重新執行 notebook cell;Claude 讀取或編輯過 Jupyter notebook 後會顯示一次
