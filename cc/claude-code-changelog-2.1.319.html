Claude Code 2.1.319 更新日誌

翻譯自 官方 CHANGELOG

2.1.319

  • 變更了關閉 telemetry 或 feature flag 時的 auto mode 行為（包含在 LLM gateway 後方的情況）：伺服器無法檢查的呼叫會被詢問或拒絕，而且不會退回內建的分類器；設定 CLAUDE_CODE_AUTO_MODE_SERVER=0 可以繼續沿用（Bedrock、Vertex 和 Foundry 不受影響）
  • 變更了 LLM gateway 後方的 auto mode：即使有設定 CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS，CLAUDE_CODE_AUTO_MODE_SERVER=1 仍會開啟伺服器端檢查；如果 managed settings 設了後者，就也必須把前者設成 1
  • 新增終端機中 MCP 任務的支援：當 MCP server 把一個工具呼叫當成任務來執行時，Claude Code 會立刻把它移到背景，等它完成後再把結果告訴 Claude
  • 新增 CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND 環境變數，讓 Claude Code 在工具呼叫裡等 MCP 任務跑完，而不是立刻把它丟到背景
  • 新增 permissions.denyInsteadOfPrompting 設定：原本會卡在權限提示的工具呼叫會直接被拒絕、然後繼續往下跑，這在終端機 session、subagent 和隊友（teammate）中都適用
  • 新增 /claude-api latency-optimize，用來找出你的 Claude API 程式碼在哪裡讓使用者等太久，並拿你的 eval 試跑更快的設定
  • 新增 CLAUDE_CODE_DISABLE_FEATURE_FLAGS 環境變數，可以停掉 feature flag 的抓取但不關閉 telemetry；這樣每個 flag 都會用它內建的預設值
  • 在 /usage 中新增今日、本週和本月的花費，給那些在 Claude apps gateway 後方、沒有花費上限的開發者看（前提是 gateway 跑的是這個版本以上）
  • 在 Claude apps gateway 新增 admin.pooled_conflict_rule 和 admin.pooled_priority_order，用來設定當某個開發者同時屬於多個群組時，要先由哪個共用群組預算付費
  • 在 Claude apps gateway 新增一個可選的 login_notice 設定，會在 gateway 的瀏覽器驗證頁面和 Claude Code 的登入畫面上顯示營運方自訂的訊息
  • 在 Claude apps gateway 新增 CLAUDE_GATEWAY_LOG_FORMAT=json：營運日誌會變成 JSON，含有 severity、time 和 message 欄位，方便那些從欄位讀取等級的日誌收集器使用
  • 在 Claude apps gateway 新增一個開機警告，用於另一個 policy 的 availableModels 也允許某個 policy 以名稱列出的自訂 model id 的情況
  • 在 Claude apps gateway 新增啟動警告，針對那些沒有 desktopHome、卻依賴 coworkTabEnabled: false 或 chatSessionRetentionDays 的 policy，以因應 Claude Desktop 11 月 10 日的變更
  • 新增一個警告：當你的 claude.ai 登入過期、而 Claude Code 繼續沿用 ant auth login 的登入時會提醒你，因為這會把用量計費到你的 Claude Console 組織
  • 在啟動時新增一行訊息，標明當 Claude Code 使用 ant auth login 的登入時，被計費的是哪個 Claude Console 組織
  • 在 /tasks 新增一列「Earlier in this session」，列出已完成的 subagent，這樣即使它已離開清單、或你重啟過，你也能重新打開並傳訊息給它
  • 在雲端 session 的 /loop 確認訊息中新增一則說明：計時器會隨容器一起停止，並提供一個能存活下來的 loop 選項
  • 修正了使用舊版 handshake 的 MCP server 連不上、或回傳空結果的問題，原因是 Claude Code 宣告了一個只會對較新 server 使用的擴充功能
  • 修正了 claude.ai connector 上長時間執行的 MCP 工具呼叫，在 --resume 後有時永遠不回報結果的問題
  • 修正了當 Claude Code 執行所在的資料夾裡有名為 HEAD 的檔案或資料夾時，session 的 diff 在 claude.ai 和行動 App 上載入失敗的問題
  • 修正了當 git repository 的最上層有名為 HEAD 的檔案或資料夾時，/diff 顯示「Diff unavailable」的問題
  • 修正了在有 64 個或更多輪次編輯過檔案的 session 中，/diff 面板打開時一片空白的問題
  • 修正了在開頭有空格、tab 或換行後才輸入的 slash command 被當成純文字送給 Claude、而不是真的執行的問題
