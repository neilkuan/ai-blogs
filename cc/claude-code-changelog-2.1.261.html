Claude Code 2.1.261 更新日誌

翻譯自 官方 CHANGELOG

2.1.261

  • /status 和 claude doctor 新增了一行「Organization policy」，會說明為什麼你組織的政策無法載入，例如 proxy 沒有把 endpoint 轉發過去
  • 新增 bashOutputMaxChars 和 taskOutputMaxChars 設定，可以拉高指令和背景任務的輸出在存進檔案前直接內嵌給 Claude 的量，最多到 128K 字元
  • 新增 --append-subagent-system-prompt-file，可以從檔案讀取 subagent 的 system prompt，適合太大、沒辦法直接放在命令列上的 prompt
  • 新增 /skill-doctor，會顯示哪些載入的 skill 根本沒在用、以及它們吃掉多少 context，方便你清掉
  • 修正快速輸入或按鍵重複時，打字或貼上的字元偶爾會亂序或掉字的問題
  • 修正當工作目錄位於 /net automount 上時，/add-dir <subdirectory> 會印出假的「couldn't be resolved」錯誤的問題
  • 修正 Bedrock 設定精靈（setup wizard）在 AWS 或 AWS 憑證輔助程式一直沒回應時卡住的問題（現在會逾時並給出清楚的錯誤），以及它的模型檢查在會檢查 TLS 的 proxy 後面失敗的問題
  • 修正 cloud session 在受管理設定（managed settings）於 enabledPlugins 中強制啟用某個從 claude.ai 同步過來的 plugin 時，反而把它丟掉、然後退回去用一個可能會失敗的 marketplace 複製品的問題

  • 修正從連上的手機或瀏覽器停止某一輪（turn）之後，或執行像 /clear 這類本機 slash 指令之後，Remote Control session 還顯示成在運作中（卡住的轉圈圈和 Stop 按鈕）的問題

  • 修正 gcpAuthRefresh 在 Google 憑證檢查很慢時，即使憑證其實還有效，卻還是在啟動時開瀏覽器的問題
