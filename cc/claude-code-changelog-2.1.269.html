Claude Code 2.1.269 更新日誌

翻譯自 官方 CHANGELOG

2.1.269

  • 新增 claude plugin eval：針對 Claude Code 跑 plugin 的 eval 測試套件，取得評分過、可重現的結果（JSON + HTML 報告）；詳見 claude plugin eval --help
  • 新增 /output-style [name] 可列出並切換 output style，包含透過 Remote Control 以及在雲端與其他 headless session 中使用
  • 當 Bash 工具處理檔案編輯時，在 Bash 工具結果中加入該 Bash 指令變更檔案的 diff（設定 bashEditDiffEnabled）
  • 新增 OTEL_METRICS_INCLUDE_REPOSITORY，可為 OpenTelemetry 的 metrics 與 events 標上 vcs.* 儲存庫屬性；搭配 OTEL_LOG_TOOL_DETAILS 時，commit events 會取得 vcs.ref.head.*
  • 新增 CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS，可延長 LLM gateway /v1/models 探索的逾時時間（預設 3 秒）
  • 新增一則 spinner 提示，建議使用 /focus 來檢視只含你的提示、一行工作摘要與回應的畫面
  • 新增 CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS（1–256），可提高 Workflow 工具每次執行的並行 agent 上限，適用於受推論限制（inference-bound）的 fan-out
  • 修正回應在 output-token 上限被截斷並自動接續後，下一輪 prompt cache 被部分失效的問題
  • 修正在 Claude 思考到一半時中斷後，再恢復 session 可能改變先前 context 的重送方式，進而損害 prompt-cache 重用的情況
