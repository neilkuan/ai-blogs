Claude Code 2.1.219 更新日誌

翻譯自 官方 CHANGELOG

2.1.219

  • 新增 Claude Opus 5（claude-opus-5），現在是預設的 Opus 模型 — 1M context，fast mode 定價 $10/$50 per Mtok
  • 新增 sandbox.network.strictAllowlist 設定，對沙箱指令中不在白名單的主機直接拒絕連線，不再跳提示
  • 新增 DirectoryAdded hook，在使用 /add-dir 或 SDK 的 register_repo_root control request 於 session 中途註冊新工作目錄時觸發
  • 新增 mcp_server_errors 至 headless stream-json 的 init event，列出被 config 驗證跳過的 --mcp-config 項目；終端執行時會印出啟動警告
  • 新增 workflowSizeGuideline settings key，讓 Dynamic workflow 的建議大小指引可從任何 settings 檔設定；設定後 /config 中對應列會隱藏
  • 新增巢狀 subagent 轉發功能至 stream-json：depth-2 以上產生的 subagent 現在會在 --forward-subagent-text 啟用時顯示，以其產生端 Agent tool_use id 為 key
  • 修正 claude -p 的文字輸出在 mid-stream API error 導致 turn 中斷時，會把已經產生的回答整個丟掉的問題
  • 新增 HTTP status 及錯誤訊息至 claude mcp list 和 /mcp，在 server 連線失敗時顯示；同時對 MCP config 值含有隱藏的前後空白時發出警告
  • 修正在 self-hosted runner 重啟期間核准的權限被 session 恢復時丟棄的問題，現在已核准的操作會正常執行
  • 修正 Fable 模型列在方案已包含該模型時仍顯示「Requires usage credits」，原因是過期快取把標籤寫死了
  • 修正 SIGTERM 在 self-hosted runner 啟動中抵達時，留下過期的 active row 直到 lease 過期的問題；現在會正確反註冊
  • 新增結構化的失敗分類至 self-hosted runner 的 spawn 及 session 失敗，讓 hook 錯誤、runner crash 和 config 錯誤可以區分
  • 修正 /model 選單把合併後的 Opus 列顯示為「Opus」而非「Opus (1M context)」
  • 修正在 GNU screen 中使用 copy-on-select 時，會把 base64 字串印到終端而非複製選取內容
  • 修正 Remote Control 客戶端在切換模型、重連或 org check 失敗後仍保留過期的 fast-mode 狀態
  • 修正 CLAUDE_CODE_GIT_BASH_PATH 在 Windows 上指向非 bash/sh 執行檔時會直接退出或被當成 bash 使用的問題；現在會忽略並發出警告
  • 修正 Vim mode：在空白 prompt 按 ← 現在無論 NORMAL 或 INSERT mode 都能回到 agent 畫面（之前只有 INSERT mode 有效）
  • 修正螢幕閱讀器模式在每次按鍵都重寫整行輸入，而非只回報剛打的字元
  • 改善「Remote Control is only available via api.anthropic.com」錯誤訊息，現在會指出是哪個設定造成的
  • 改善 claude --teleport，當你當前的 checkout 指向的 repo 與 session 的 repo 不同時，會顯示你指向的是哪個 repo
  • 變更 dynamic workflows 預設為 medium 大小指引（目標少於 15 個 agent）；可在 /config 的 Dynamic workflow size 選擇其他大小或不限制
  • 變更 managed MCP allowlist/denylist 中的 ${VAR} 解析來源，從 settings 檔環境改為啟動環境和 managed-settings env
  • 變更 /model 選單只高亮最新模型的名稱，讓高亮標示新發布的模型而非清單中任意子集
  • 新增目前預設的 workflow 大小至執行中 workflow 的狀態列，並附上指向 /config 的提示以供調整
  • 移除 Opus 4.7 的 fast mode 支援；/fast 現在適用於 Opus 5 和 Opus 4.8
  • 更新 claude-api skill 預設使用 Claude Opus 5，並提供從 Opus 4.8 的遷移路徑
  • Subagent 現在預設可產生巢狀 subagent 至深度 3（原本是 1）；設定 CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 可停用巢狀功能
