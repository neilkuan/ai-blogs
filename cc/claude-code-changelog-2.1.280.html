Claude Code 2.1.280 更新日誌

翻譯自 官方 CHANGELOG

2.1.280

  • 新增 Claude Opus 5.5（claude-opus-5-5），現在是預設的 Opus 模型 —— 1M context，每 Mtok $4/$20，cache 讀取每 Mtok $0.20
  • 在全螢幕模式下更多清單支援滑鼠操作：滾輪可捲動 /skills 清單，/plugin 裡某個 skill 的狀態選項也可以用點的
  • 新增 CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH，可調整 session 中每個 MCP server 的 MCP 工具描述與 server 指示的 2,048 字元上限
  • 在 hook_execution_complete OpenTelemetry 事件中加入 hook 輸出大小，以及被存到檔案的過大輸出數量
  • 修正透過 symlink 路徑寫入時，會以路徑在目錄樹內的寫法來判斷的問題：現在提示會顯示寫入實際落點的位置，而 acceptEdits、allow 規則和 auto 模式不再核准落到目錄樹外的寫入
  • 修正 auto 模式在安全檢查拒絕審查某個動作時，會不斷重試該動作的問題；現在該動作會被拒絕一次，並註明重試也沒用
  • 修正 auto 模式在安全檢查沒有回應時，會毫不停頓地一直拒絕動作的問題；現在重試會逐步退避（back off），連續十次後該回合會停下並顯示訊息
  • 修正當模型傳送 path、file_text、file_content 或多餘的 description 而非 file_path 和 content 時，Write 呼叫驗證失敗的問題
  • 修正在大多數對話框（/model、/effort、/config、/status、/usage、/plugin、/sandbox、/permissions、/artifacts、/mobile、/login、/upgrade、/usage-credits、/install-github-app、/setup-bedrock、/setup-vertex）中按兩次 Ctrl+C 或 Ctrl+D 會直接關閉 Claude Code，而不是關閉對話框的問題
  • 修正只是把終端機視窗帶到最前面的點擊，卻同時觸發游標下方項目的問題 —— 出現在搜尋選單、分頁列、agent/workflow 列、slash command 連結和建議下拉選單中
  • 修正多餘的 n 會關閉對話框、多餘的 y 會確認對話框的問題；現在由 Enter 和 Esc 負責接受和取消（想恢復舊行為，可在 keybindings.json 把 y/n 綁定到 confirm:yes/confirm:no）
  • 修正對話框裡的文字欄位，會因為某個按鍵綁定而吃掉你輸入的字母、數字或空格的問題
  • 修正在 Windows 終端機上，Enter 移除隱形字元後提示列仍維持錯亂的問題；現在畫面會重新繪製，讓你檢視實際會送出的文字
  • 修正隱形字元清理時，誤刪波斯文和阿拉伯文用來把後綴接到拉丁文單字或數字上的零寬不連字（zero-width non-joiner）的問題，例如「PDF」的複數形
  • 修正語音聽寫（voice dictation）在 Ctrl+C 時不會停止（提示已清空但麥克風仍在錄音）、在處理逐字稿時 Esc 無法取消，以及在逐字稿檢視和 vim NORMAL 模式下按住空格會開始聽寫的問題
  • 修正 Claude 工作期間，從 host app（Claude Desktop、VS Code、SDK）切換模型，導致下一個提示發生 prompt-cache 未命中的問題
  • 修正恢復（resume）的分岔 subagent 會重建工具清單，而不是重新送出最初使用的那份，導致該 agent 的 prompt caching 失效的問題
  • 修正 subagent 交回（hand-back）訊息在非 verbose 模式下展開時，會顯示內部來源（provenance）前言的問題
  • 修正從追蹤某個分支或 tag 的 GitHub repo 或 git URL 更新 plugin 後，installed_plugins.json 仍保留安裝當下 commit 的問題
  • 修正當 ~/.claude/skills/ 資料夾裡的 manifest.json 列出某些 skill 名稱時，這些 skill 會被移到 ~/.claude/skills/.trash/ 的問題
  • 修正 session 意見回饋問卷在 light 和 ANSI 主題下沒有 hover 高亮的問題
  • 修正 /workflows 在開啟唯一一筆執行之前，會短暫顯示只有一列清單的問題
  • 修正在全螢幕模式下，滑鼠滾輪無法捲動含有隱藏選項的選取清單（例如 /model 和 /permissions）的問題
  • 修正你關掉的 skill 會在 /plugin 和 /skills 顯示成跟載入失敗 plugin 一樣的紅色 ✘ 的問題；現在關閉狀態會顯示暗色的 ◯
  • 修正多選（multi-select）選項描述縮排在選項編號下方，而非標籤下方的問題
  • 修正 /plugin、/skills 和 /mcp 的搜尋框在全螢幕模式下失去右邊框的問題
  • 修正同一個 server 在 /mcp 的 server 清單顯示 △、但在詳細檢視顯示 ⚠ 的問題；現在清單、詳細檢視和 /plugin 都統一顯示 ⚠
  • 修正 Home 和 End 在 /config 設定清單，以及 /model、/memory 和權限提示等選取清單中沒有作用的問題
  • 修正 /skills 選單裡 PgUp/PgDn 會越過第一個或最後一個 skill 繞回，而非停在該處的問題
  • 修正 Tab 在 /config 清單中會默默改掉所選設定的值的問題；現在它在那裡不會有任何作用
  • 修正對話每個回合都失敗、出現「role 'system' must precede an 'assistant' message」API 錯誤的問題
  • 修正在不支援 advisor 的 proxy 或 gateway 後方時，開啟 advisor 的對話每個回合都以 API 錯誤 400「Input tag 'advisor_20260301'」失敗的問題；現在請求會不帶它重試
  • 修正當 session 儲存的歷史中，含有一則格式錯誤、關於無法載入 MCP 工具的通知時，該 session 每個回合和 /compact 都失敗的問題
  • 修正恢復 session 時，其儲存的逐字稿含有格式錯誤的系統訊息、或缺少檔案清單的記憶已儲存通知，會導致當機的問題
  • 修正長時間執行的全螢幕 session 以「Claude Code exited after an unrecoverable interface error」退出的其中一個原因：現在會重建損毀的快取訊息清單
  • 修正當設定檔、或編輯後會重新讀取的檔案，在讀取中途被具名管道（named pipe）取代時，Claude Code 會卡住的問題
  • 修正當一個已移到 settings.json 的偏好設定，在 ~/.claude.json 裡仍保有像 null 或 "false" 這類值時，/config 當機、以及某些開/關偏好被誤讀的問題
  • 修正恢復含有未完成背景 agent、shell 或 workflow 的 session 時，會在你還沒輸入任何東西前就自行開始一個模型回合的問題
  • 修正在 headless 和 SDK session 中，當 subagent 正在結束其回合時，送給該背景 subagent 的訊息會被默默丟失的問題
  • 修正當啟動某個 subagent 的對話在其報告被讀取前就被壓縮（compact），導致該完成 subagent 的報告遺失的問題
  • 修正當有 LSP plugin 啟用時，背景 subagent 無法使用 LSP 工具的問題
  • 修正背景 shell 任務把良性的非零退出（例如 grep 沒有比對到結果）回報為失敗的問題
  • 修正當交給 session 的環境變數含有 NUL 字元時，背景 session（claude --bg）無法執行 git、hook、plugin 和其他輔助程式的問題
  • 修正背景 subagent 執行時，需要按三、四次 Ctrl+C 才能退出的問題；現在按兩次即可退出
  • 修正當已送出的提示回到輸入框時（例如按 Esc 編輯它、倒回到它，或在啟動 hook 執行時按 Esc），IDE 選取內容會被丟棄的問題
  • 修正用 Ctrl+S 暫存的 ! shell 模式提示，還原時會變回一般提示的問題，以及暫存後立刻用 / 會列出檔案路徑的問題
  • 修正當暫存目錄已滿、不可寫入或屬於其他使用者時，claude agents 會顯示空白、無回應的畫面而非錯誤的問題
  • 修正在 claude mcp remove 之後又以相同名稱重新加入的 MCP server，仍顯示為需要驗證而非重新連線的問題
  • 修正背景 plugin marketplace 自動更新忽略 git 憑證輔助程式（credential helper），導致私有 repo 的 marketplace 每次執行都重新 clone 或從不更新的問題
  • 修正當官方 marketplace 的快照檔是連結或過大時，claude plugin update 會清掉 plugin 記錄的 commit、並把它移到版本「unknown」的問題
  • 修正當你組織的政策無法載入時（例如在 web proxy 後方），Artifact 工具會默默消失的問題；現在 Claude 會說明是什麼在阻擋它
  • 修正 artifact 重新發布時，當某項能力被重送但未附帶資料時，會默默重設已儲存的資料庫存取規則、或丟掉檢視者設定檔範圍（scope）的問題；現在這類重送會被拒絕
  • 修正 /ultrareview 把已停止的雲端審查回報為已完成、或回報為可重試的錯誤，以及當其 session 被刪除或登入帳號變更時仍苦等到逾時的問題
  • 修正 Claude app 在 /compact 或 /clear 後，對 Remote Control 和雲端 session 顯示缺失或過期的 context 使用量數字的問題
  • 修正 Claude app 對 Remote Control 和雲端 session 的 diff 檢視，在同時有未提交變更時會漏掉某分支已提交檔案的問題
  • 修正雲端和自架 runner session，在撐過一段長時間過載（session 的存取權杖在此期間輪替過）後以「Authentication failed」失敗的問題
  • 修正 Cowork session 的記憶寫入衝突時，只給 Claude 看超過約 10,800 字元記憶檔的開頭和結尾，導致重試寫入時漏掉中間的問題
  • 自架 runner：修正在 --configure-git 下 lifecycle-hook commit 無法簽章的問題
  • Windows：修正背景清理誤刪用來重新定位 ~/.claude/session-env、image-cache 或其他被清理資料夾的目錄 symlink 或 junction 的問題
  • 自架 runner：修正一個剛好在 --retire-at 釋出時結束的回合會遺失其完成訊號的問題；現在 runner 會在停止 session 前，短暫等待該回合被回報
  • 還原了全螢幕模式下 ctrl+l / cmd+k 清除逐字稿檢視的行為（於 2.1.260 加入）；它們現在恢復為重繪畫面
  • 改善 /permissions：檢視、新增或刪除規則後，焦點會回到規則清單，而刪除規則和移除目錄的確認現在預設為 No
  • 改善 /permissions 的分頁導覽：在規則清單中按 ←/→ 和 Tab 現在會切換分頁，而不會把焦點移到分頁列
  • 改善 /cost 的 cache 未命中原因說明，會點名 thinking 模式和 thinking 顯示的變更
  • 改善 Artifact 工具，當 Claude 無法讀取拿到的 artifact 連結時，會在繼續之前先告知使用者

  • 改善 workflow 進度樹：執行中的 agent 和階段現在顯示暗色圓點，而非 ⟳
  • 改善 /plugin 全螢幕的 Add Marketplace 表單：它不再於窗格內畫一個框，而且文字和按鍵提示會與 /plugin 其餘部分對齊
  • 改善全螢幕的 /workflows 詳細檢視：它不再於窗格分隔線下方畫第二條水平線
  • 改善未指定語言的程式碼區塊：現在會以行內程式碼的顏色上色，讓指令從周圍文字中凸顯出來

  • 改善 @ 檔案建議：名稱含有查詢字串的檔案現在排在只靠資料夾名稱比對到的檔案上面
  • 改善 artifact 頁面：不再有 Print 按鈕、確認對話框或檢視者封鎖的裝置功能，email 和電話細節以純文字顯示，且深色模式會延伸到表單控制項和捲軸
