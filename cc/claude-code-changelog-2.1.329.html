Claude Code 2.1.329 更新日誌

翻譯自 官方 CHANGELOG

2.1.329

  • 新增信任對話框警告，會標示資料夾的 hook 是在哪裡宣告的
  • 在 Claude Desktop 和其他非互動式（non-interactive）host 中，當受管設定（managed settings）裡的 hook 載入失敗時，對話中會顯示警告
  • /tasks 現在會列出本次工作階段（session）的排程任務、/loop 喚醒、goal，以及這段對話的 fork；按 x 會先確認再停止
  • 在 /mcp 的伺服器頁面新增「Server message」欄位，當遠端 HTTP MCP 伺服器拒絕連線時，會顯示它回傳的 JSON-RPC 錯誤訊息
  • 在 /status 新增「Marketplace auto-update」欄位，會列出沒有自動更新的受管 marketplace 以及原因
  • 新增支援在啟用 OpenTelemetry 事件與指標時開啟 Code Mode；程式碼的每次工具呼叫都會送出對應事件；啟用追蹤（tracing）時仍會維持關閉
  • 修正 ~/.claude.json 有時會被重設為預設值的問題：當網路停滯或檔案鎖定導致檔案無法讀取，並在儲存過程中被清空
  • 修正 macOS 上重複被登出的問題：當 Claude Code 能讀取 Keychain 卻無法寫入時，現在該工作階段會在到期時停止並說明原因，其他工作階段則維持登入
  • 修正 /terminal-setup 在區塊註解（block comment）附近損毀 VS Code 設定檔或快捷鍵檔的問題，以及在 keybindings.json 含有未關閉字串時，明明遺失了 Shift+Enter 綁定卻回報成功的問題
  • 修正透過 IDE diff 接受的檔案被存成缺少最後換行的問題，以及在 VS Code 中以儲存 diff 的方式接受編輯時，檔案遺失位元組順序標記（BOM）的問題
  • 修正在 /teleport 選擇雲端工作階段會取代你目前開啟的對話：現在選擇後會像 /clear 一樣開啟新的工作階段，並可用 /resume 找回舊的
  • 修正 /usage-credits 在開啟瀏覽器後又要求 Pro 和 Max 使用者重新登入的問題；以及當瀏覽器沒有開啟、且任務因用量額度（usage credits）而停止時，連結 8 秒後就消失的問題
  • 修正 /usage 在用量額度已用完或達到每月上限時，仍顯示額度為關閉的問題；以及 /model 在該上限擋住使用額度計費的模型時，沒有告知 Pro 和 Max 使用者的問題
  • 修正支出上限選單把你的支出顯示成每月上限的問題，以及在狹窄視窗中，選單列會換行到游標下方的問題
  • 修正狀態列（status line）腳本無限輸出時，會凍結提示輸入並佔用數 GB 記憶體的問題
  • 修正在核准受管設定後，若 --resume 選擇器、信任對話框或其他設定畫面正在等待，會出現空白凍結畫面的問題
  • 修正在 /model 選擇 Default 時，即使 Default 該列已顯示你儲存的模型，仍會用你組織的預設值覆蓋它的問題
  • 修正在權杖更新（token refresh）進行中清除 MCP 伺服器的驗證後，該伺服器又被重新登入的問題
  • 修正背景 MCP 任務在緩慢重新連線後卡住的問題：當 HTTP MCP 伺服器停留在較舊的協定版本時，Claude Code 現在會自動重新連線大部分這類伺服器
  • 修正 MCP 伺服器或網站以 application/octet-stream 傳送的 PDF、圖片，以及 .docx、.xlsx、.pptx 檔案被存成 .bin，導致 Claude 無法讀取 PDF 和圖片的問題
  • 修正 /code-review <pr number> 有時會在沒有說明的情況下審查目前 checkout 的分支，而不是該 pull request：現在會用 gh pr diff 讀取 pull request，無法讀取時會明確告知
  • 修正 /code-review 在大多數模型上，會為了尋找一個不存在的 ~/.claude/CLAUDE.md 而停在權限提示的問題
  • Self-hosted runner：修正 --push-outcome-on-release 有時會刪除 git host 上工作階段分支的問題
  • 修正 Code Mode 在按 Esc 後，會隱藏腳本已完成的編輯和被停止的指令，且在退出時遺失它們的問題
  • 修正 Code Mode 中失控的迴圈會塞爆機器記憶體的問題；現在會在達到上限時停止
  • 修正背景 agent 在恢復過程中被停止，卻仍繼續執行的問題
  • 修正背景 shell 指令在結束前，一直佔用記憶體保存先前對話的問題
  • 修正在由 Claude Desktop、IDE 或 SDK 執行的工作階段中，Remote Control 在壓縮（compaction）或 /clear 之後仍佔用記憶體保存先前對話的問題
  • 修正在 Bedrock 上的 Claude Desktop 工作階段中，當 AWS credential_process 或登入呼叫卡住時，Stop 無法結束請求的問題
  • 修正在 Opus 4.8 和 Opus 5 上，Claude 有時第一次嘗試傳送檔案給你會失敗的問題
  • 修正在有工具搜尋（tool search）的工作階段中，Claude 沒被告知已連線 MCP 伺服器的工具載入失敗，而把它當成沒有工具的伺服器的問題
  • 修正當服務的 client 註冊已被撤銷（HTTP 410 Gone）時，claude mcp login 和 /mcp 錯誤地顯示該服務不接受來自 Claude Code 登入的問題
  • 修正在 macOS 上，工作階段仍在執行時，claude.ai 同步的 plugin hook 因「Plugin directory does not exist」而失敗的另一種情況
  • 修正 auto mode 在對指向工作目錄之外、或指向自己的符號連結（symlink）執行 rm 時，要求手動核准的問題
  • 修正 Linux 上 /sandbox 把 allowUnixSockets 項目列為已允許的問題：這些 socket 在 Linux 上實際不會開啟，/sandbox 現在會明確說明
  • 修正在 /install-github-app 中，按兩次 Esc 清除輸入錯誤的程式碼時，會連帶結束登入的問題
  • Remote Control：修正重啟後工作階段回到最初的 effort 等級，但 app 仍顯示你選的等級的問題（尚未涵蓋以 Ultracode 啟動的工作階段）
  • 修正在無介面（headless）工作階段中，執行 reload_plugins 之後或帳號的 plugin 清單已移除該 plugin 時，被移除 plugin 的 MCP 伺服器仍保持連線的問題
  • 修正當同位址的 plugin 或 MCP 伺服器連線失敗時，Claude Docs connector 的工具會消失，且錯誤訊息錯誤地建議執行 /login 的問題
  • 修正在 --add-dir 指定工作目錄、或 Claude Code 在家目錄啟動時，新的 skills、commands 或 agents 資料夾被漏掉的問題
  • 修正從預先暖機（pre-warmed）的行程啟動的工作階段，會忽略專案 .claude/settings.json 中 autoCompactWindow 設定的問題
  • 修正 CLAUDE_AUTOCOMPACT_PCT_OVERRIDE 從 settings.json 移除後，仍在執行中的工作階段持續生效的問題
  • 修正 Agent 工具的 effort 參數在 agent teams 中對具名隊友（teammate）被忽略的問題
  • 修正 /auto-mode-setup 在掃描專案以建議規則時，忽略近期 auto mode 拒絕紀錄的問題；現在可能會根據這些紀錄提供允許規則，且每一條都會先讓你檢視再儲存
  • 修正在 .claude/settings.local.json 無法讀取或格式錯誤的子資料夾或 worktree 中新增權限規則或目錄後，出現誤報「Couldn't save this change」警告的問題
  • 修正雲端工作階段在請求失敗後，叫 Claude 執行網路代理檢查，然後被 auto mode 擋下的問題
  • 修正在模型變更後立刻送出訊息、而該訊息仍在等待模型變更時，headless 的 rewind 和 fork 就先行執行的問題
  • 修正雲端工作階段重啟期間背景任務被停止時，Claude 沒有被告知的問題
  • 修正 /team-onboarding 在伺服器拒絕上傳時，仍在 Team 和 Enterprise 方案回報指南已分享的問題
  • 修正全螢幕下面板和問題在提示處被截斷、/help、歷史搜尋和背景任務清單在矮視窗中遺失列或標題，以及對話框中表格換行的問題

  • 修正 /passes 在伺服器錯誤後顯示錯誤的 pass 數量，以及在沒有剩餘訪客 pass 時，仍提供用額度來分享的問題
  • 修正 claude --help 的輸出在透過管線（pipe）傳給其他程式時被截斷的問題
  • 修正 /terminal-setup 在 macOS 27 的 Terminal.app 中開啟「Use Option as Meta key」，以及該處的提示建議用 Option+Enter 而非 Shift+Enter 的問題
  • Self-hosted runner：修正透過 Anthropic 託管的 git clone 的 Git LFS 儲存庫設定失敗的問題；現在工作階段會從指標檔（pointer file）開始，並可用 git lfs pull 取得內容
  • 修正在自架環境中，工作階段無法從使用 SSH host 別名、GitHub SSH 憑證或 GHE.com SSH 使用者的 git remote 啟動的問題；無法解析的別名所產生的錯誤會給出兩個 git 指令

  • 修正 Code Mode 腳本在大多數超過兩分鐘的 MCP 呼叫中，把「moved to the background」訊息當成資料收到的問題：現在腳本會等待最多十分鐘，之後才收到錯誤
  • 修正只列出部分工具的 mod 會默默關閉 Code Mode 的問題；這類 mod 不再讓它保持關閉，若要這麼做請使用受管設定

  • 修正記憶體不足時，畫面更新有時會被跳過的問題
  • 修正長程式碼區塊在捲動緩衝區（scrollback）中遺失一個空行、又重複另一個的問題

  • 修正提示文字含有會設定多種樣式的顏色碼，且關鍵字或指令被醒目標示時，字元從提示中消失的問題
